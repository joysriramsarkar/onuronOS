# বাস্তব বুট থেকে শুরু করে সমগ্র অনুরণ ওএস সম্পূর্ণ করা - কোডসহ বিস্তারিত নির্দেশনা

> লক্ষ্য: বর্তমান কোডবেসে যেসব জায়গায় `stub`, `simulated`, `mock`, `fake-fallback` আছে সেগুলো বাস্তব ইমপ্লিমেন্টেশনে রূপান্তর করা।  
> শর্ত: কোনো নতুন স্টাব তৈরি করা যাবে না। যেই হার্ডওয়্যার নেই সেক্ষেত্রে graceful degrade নয়, বরং বাস্তব পথ সক্রিয় করতে হবে।  
> লক্ষ্য প্ল্যাটফর্ম: QEMU (reproducible) থেকে শুরু করে আসল রেফারেন্স মোবাইল ডিভাইসে বাস্তব বুট।

## ১. বাস্তব অবস্থা মূল্যায়ন

বর্তমান কোডবেস বিশ্লেষণ অনুযায়ী নিচের জিনিসগুলো **বাস্তব** হলেও কিছু জায়গায় **সিমুলেটেড/স্টাব** রয়েছে।

| অংশ | বর্তমান অবস্থা | কাজ |
|---|---|---|
| `nilinit` | FUNCTIONAL PROTOTYPE (খুব কাছাকাছি বাস্তব) | আরো হার্ডেনিং + রিকভারি + fscrypt পূর্ণাঙ্গ সংযোগ |
| `NilHAL` | MIXED | `fake` ব্যাকেন্ডকে সরিয়ে `linux`/`qemu`/`real-hal` কে ডিফল্ট করা |
| `nilrt/sandbox/seccomp/permissions/permbroker` | FUNCTIONAL PROTOTYPE | সীমাবদ্ধতা দূর করে প্রকৃত namespace/seccomp কনফিগ আরোপ |
| `nilui-gpu` (DRM/KMS) | FUNCTIONAL PROTOTYPE | `/dev/dri/card*` বাস্তব মডসেটিং, পেজ ফ্লিপ, VSYNC ভিত্তিক প্রেজেন্ট |
| `nilshell` (`shell/nilshell.c`) | STUB/SIMULATED | বাস্তব টার্মিনাল এমুলেটর (PTY + login/session + /bin/sh) + কম্পোজিটর ইন্টিগ্রেশন |
| `apps/browser`, `apps/nilbrowser` | EXPERIMENTAL/SIMULATED | বাস্তব 렌더িং ইঞ্জিন সংযুক্তি (WPE/WebKitGTK ভিত্তিক নিল Adaptation Layer) |
| `android/`, `android-host/` | STUB/SIMULATED | আলাদা সাবসিস্টেম হিসেবে নেমস্পেস + cgroups + ভলিউম + ADB isolated bridge বাস্তবায়ন |
| কিছু `services/*` | MIXED (বাস্তব + fallback) | হার্ডওয়্যার অনুপস্থিতি হলেও বাস্তব কোড পাথ চালু রাখা, কোনো `#[cfg(test)]` ভিত্তিক "fake data" প্রোডাকশন পাথ থেকে সরানো |

## ২. মৌলিক নীতিমালা (AGENTS.md অনুযায়ী মেনে চলতে হবে)

- **স্বাধীন OS**: OnuronOS কে AOSP রি-ডিজাইন করা যাবে না। Android Bridge শুধু আলাদা সাবসিস্টেম হিসেবে রাখবে।
- **বাস্তবতা**: `IMPLEMENTED` ছাড়া কিছু বলা যাবে না যতক্ষণ পর্যন্ত কোড, বিল্ড, কিউএমইউতে সত্যিকারের কার্যকর প্রমাণ না পাওয়া যায়।
- **সুরক্ষা**: `namespaces`, `seccomp`, `SELinux`, `cgroups`, `PR_SET_NO_NEW_PRIVS` কখনো বাইপাস করা যাবে না।
- **সীমা রক্ষা**: Native API (`NilLang/Alap/NilUI`) আর Android Compatibility কে সরাসরি মিলানো যাবে না।
- **সত্যিকারের ড্রাইভার পথ**: `evdev`, `DRM/KMS`, `V4L2`, `ALSA`, `RFKILL`, `sysfs`, `netlink` ব্যবহার করে বাস্তব ইন্টারফেসিং।
- **কোনো স্টাব নয়**: `"simulate"`, `"mock"`, `"fake"`, `"placeholder"`, `"TODO: replace with real"` প্রোডাকশন কোড থেকে অপসারণের লক্ষ্য রাখা।

## ৩. সম্পূর্ণ বুট চেইনকে বাস্তব করা

### ৩.১ Kernel + initramfs
ফাইল: `build/mkinitramfs.py`, `build/qemu-boot.ps1`, `build/qemu-boot.sh`, `kernel/`

**করণীয়:**

1. `mkinitramfs.py` এ নিশ্চিত করতে হবে `nilinit` সত্যিকারের বাইনারি কপি হচ্ছে (strip করা হবে না ডিবাগের জন্য দরকারি না হলে, কিন্তু রিলিজে উপযুক্ত strip)
2. `init` লিঙ্ককে `nilinit` এ poin্ট করা নিশ্চিত করা
3. মডিউল লোড অর্ডার নির্ধারণ: `virtio_blk`, `virtio_net`, `virtio_pci`, `virtio_mmio`, `drm`, `drm_kms_helper`, `evdev`, `ext4`, `ahci`, `sd_mod`, `usb_storage` ইত্যাদি
4. `/sys`, `/proc`, `/dev`, `/run`, `/sys/fs/selinux`, `/sys/fs/cgroup` মাউন্ট নিশ্চিত করা
5. `modules.dep` ভিত্তিক নির্ভরতা লোডিং বাস্তবায়ন

**পরিবর্তন (ভিত্তি):**

`build/mkinitramfs.py` এর `copy_binary` অংশে নিম্নলিখিত যাচাইকরণ যোগ করতে হবে:

```python
# mkinitramfs.py - build/initramfs verification
import subprocess, os
def ensure_real_binary(src, dst):
    if not os.path.exists(src):
        raise SystemExit(f"[INITRAMFS][FATAL] missing real binary: {src}")
    # check it's ELF
    res = subprocess.run(['file', src], capture_output=True, text=True)
    if 'ELF' not in res.stdout:
        raise SystemExit(f"[INITRAMFS][FATAL] not ELF: {src}")
    # ensure not a script stub
    with open(src,'rb') as f:
        head = f.read(4)
    if head == b'#!':
        raise SystemExit(f"[INITRAMFS][FATAL] script where binary expected: {src}")
    return src
```

### ৩.২ nilinit বুট সিকোয়েন্স বাস্তবায়ন
ফাইল: `nilinit/src/main.rs`, `nilinit/src/mount.rs`, `nilinit/src/selinux.rs`, `nilinit/src/recovery.rs`, `nilinit/src/supervisor.rs`

**মূল লক্ষ্য:**

- `/data` পার্টিশন সত্যিকার অর্থে মাউন্ট (ext4)। `ext2` fallback রাখা যেতে পারে শুধুমাত্র ডিবাগ কনসোলে স্পষ্ট লগ দিয়ে, প্রোডাকশন বুটে সতর্ক করা
- SELinux পলিসি লোড ও এনফোর্সিং
- `nilkeyd` থেকে fscrypt কী রিকভারি
- `services.toml` পার্সিং ও ভ্যালিডেশন
- Socket Activation বাস্তব
- cgroups v2 slice তৈরি
- Boot counter + last_boot_status

**প্রস্তাবিত পরিবর্তন `nilinit/src/main.rs`:**

```rust
// nilinit/src/main.rs - key points
// 1. Early mounts
// 2. Load kernel modules (real modprobe/insmod via kmod)
// 3. Mount /data from real block (virtio-blk / mmcblk / nvme)
// 4. SELinux: if policy exists load, else enter permissive with CRITICAL log and require policy
// 5. Start nilkeyd comms, unlock fscrypt if configured
// 6. Read /etc/nilos/services.toml, validate
// 7. Spawn supervisor with real service binaries
// 8. Run readiness probes
// 9. Enter service supervision loop
```

> মন্তব্য: `nilinit` ইতিমধ্যেই বেশ বাস্তব। মূল কাজ হবে fallback গুলোকে "development-only" হিসেবে `NILINIT_DEV_FALLBACK=1` ছাড়া নিষ্ক্রিয় করা।

## ৪. NilHAL - ফেইক ব্যাকেন্ড বাদ দিয়ে রিয়েল ব্যাকেন্ড সক্রিয়করণ

ফাইল: `runtime/nilhal/src/lib.rs`, `runtime/nilhal/src/backends/mod.rs`, `runtime/nilhal/src/backends/linux.rs`, `runtime/nilhal/src/backends/qemu.rs`

**করণীয়:**

1. `auto_detect()` এ `Fake` কে সর্বনিম্ন প্রায়োরিটি দিতে হবে। শুধুমাত্র `NILHAL_FORCE_FAKE=1 && cfg(test)` অথবা স্পষ্ট ডেভ টুলে অনুমোদিত
2. `linux` ব্যাকেন্ডে বাস্তব `sysfs`, `udev`, `evdev`, `DRM`, `ALSA` থেকে ডাটা পড়া
3. `display` জন্য `/sys/class/graphics/fb*/` এবং `/sys/class/drm/` থেকে রেজোলিউশন/EDID পড়া
4. `input` জন্য `/dev/input/event*` enumerasi
5. `power` জন্য `/sys/class/power_supply/` (BAT, AC, USB)
6. `network` জন্য `netlink`/`sysfs`
7. `sensors` বাস্তব সেন্সর এক্সপোজার

**`runtime/nilhal/src/backends/linux.rs` বাস্তব ধারণা:**

```rust
// runtime/nilhal/src/backends/linux.rs
use std::fs;
use std::path::Path;

impl LinuxDisplay {
    fn real_modes() -> Vec<Mode> {
        // read /sys/class/drm/card*/card*-*/modes
        // or parse EDID
    }
}
```

**পরিবর্তন:** `runtime/nilhal/src/lib.rs` এর `new()` থেকে `Fake` auto-select এর শর্ত কঠোর করা।

```rust
// শুধুমাত্র CI/TEST অথবা স্পষ্ট ENV
let force_fake = std::env::var("NILHAL_FORCE_FAKE").is_ok() && (cfg!(test) || std::env::var("NILHAL_ALLOW_FAKE").is_ok());
```

## ৫. nilinit PID 1 কে আরও শক্তিশালী করে বাস্তব করতে হবে

ফাইল: `nilinit/Cargo.toml`, `nilinit/src/*`

**যোগ করতে হবে:**

- `kmod` (বা সরাসরি `init_module/finit_module` syscall) দিয়ে বাস্তব মডিউল লোড
- `mount` syscall দিয়ে নির্ভুল মাউন্ট
- `pivot_root` যাচাইকরণ
- `cgroups v2` লিখিতভাবে enable
- `oom_score_adj` সেটিং
- সার্ভিস বাইনারির `execve` আগে `realpath` + `exists` + ELF চেক
- `systemd` নয়, নিজের supervision বজায় রেখে হার্ডেনিং

**`nilinit/src/modules.rs` (নতুন ফাইল প্রস্তাবিত):**

```rust
// nilinit/src/modules.rs
use std::fs::File;
use std::io::Read;
use nix::sys::init_module::{init_module, InitModuleFlags};

pub fn load_module_from_path(path: &str) -> std::io::Result<()> {
    let mut f = File::open(path)?;
    let mut buf = Vec::new();
    f.read_to_end(&mut buf)?;
    init_module(&buf, "")?;
    Ok(())
}
```

`Cargo.toml` এ `nix` এর যথাযথ ফিচার যোগ করতে হবে।

## ৬. সিস্টেম সার্ভিসগুলোকে বাস্তব করা (audiod, camerad, inputd, powerd, netd, btd, telephonyd, thermald)

সব সার্ভিসে লক্ষ্য: **fallback "simulated" মোডকে ডিফল্ট থেকে সরিয়ে বাস্তব হার্ডওয়্যার পথ চেষ্টা করা। ব্যর্থ হলে পরিষ্কার ERROR লগ দিয়ে নির্দিষ্ট কারন দেখানো।**

| সার্ভিস | বাস্তব পথ | পরিবর্তন |
|---|---|---|
| `services/audiod` | ALSA (`libasound`) / Pulse/PipeWire নয়, সরাসরি ALSA PCM + mixer | `simulate` if no card -> `EALREADY`/`ENODEV` সহ বিস্তারিত লগ। `alsa-lib` এর সাথে বাস্তব ওপেন |
| `services/camerad` | V4L2 (`/dev/video*`) + VIDIOC_* ioctls | `v4l2loopback` কখনো প্রোডাকশন ডিফল্ট না। ফরম্যাট enum, buffer mmap, streamon বাস্তব |
| `services/inputd` | evdev (`/dev/input/event*`) + uinput (যদি প্রয়োজন) | libinput নয় শুরুতেই evdev সরাসরি, গ্র্যাব/এক্সক্লুসিভ হ্যান্ডলিং |
| `services/powerd` | `/sys/class/power_supply/*`, `uevent`, `ACPI` | চার্জিং/ডিসচার্জিং/ক্যাপাসিটি/ভোল্টেজ বাস্তব পড়া |
| `services/netd` | `netlink` (rtnetlink), `iproute2` logic নিজস্ব, `wpa_supplicant` নয় চাইলে `iwd` ইন্টারফেস বাস্তব | interface up/down, addr, route, dhcp client ইন্টিগ্রেশন যাচাই |
| `services/btd` | BlueZ HCI? অনুরণ এর নিজস্ব নীতি অনুযায়ী বাস্তব RFKILL + `hci` ভ্যারিয়েন্ট | `rfkill` sysfs বাস্তব, ব্লুটুথ ডিভাইস ডিটেকশন |
| `services/telephonyd` | oFono/ModemManager নয়, AT+PPP বা QMI/MBIM বাস্তব পথ যাচাই | হার্ডওয়্যার ছাড়া কখনো "fake call" সার্ভিসে এক্সপোজ করা যাবে না |
| `services/thermald` | `/sys/class/thermal/thermal_zone*/` | থ্রেশহোল্ড + একশন বাস্তব |

**নির্দেশ:** প্রতিটি সার্ভিসের `main.rs` এ `if simulate { ... }` ব্লক খুঁজে বের করে বাস্তব init এর আগেই হার্ডওয়্যার প্রোব করে, ব্যর্থ হলে সার্ভিস `FAILED` হিসেবে রিপোর্ট করবে (nilinit দেখে ঠিকমতো হ্যান্ডেল করবে)।

## ৭. নিলশেল (nilshell) কে বাস্তব টার্মিনাল কম্পোজিটর হিসেবে তৈরি করা

বর্তমানে `shell/nilshell.c` অনেকটাই স্টাব। লক্ষ্য: **বাস্তব PTY + shell + লগইন সেশন + nilui কম্পোজিটর সাথে সংযুক্তি**।

### ৭.১ প্রয়োজনীয় ফাইল
- `shell/nilshell.c` (পুনর্লিখন অংশ)
- `shell/terminal/` (নতুন ডিরেক্টরি) - `pty.c/h`, `vt.c/h`, `tty_io.c/h`, `render.c/h`
- `shell/session.c/h`
- `shell/compositor_bridge.c/h`

### ৭.২ বাস্তব PTY টার্মিনাল
`shell/terminal/pty.c`

```c
// shell/terminal/pty.c
#define _GNU_SOURCE
#include <fcntl.h>
#include <unistd.h>
#include <stdlib.h>
#include <termios.h>
#include <sys/ioctl.h>
#include <pty.h>
#include <utmp.h>

int term_create_pty(pid_t *child, int cols, int rows) {
    int master;
    struct winsize ws = { .ws_row = rows, .ws_col = cols };
    pid_t pid = forkpty(&master, NULL, NULL, &ws);
    if(pid == 0) {
        setenv("TERM", "xterm-256color", 1);
        setenv("SHELL", "/bin/sh", 1);
        execl("/bin/sh", "-sh", (char*)NULL);
        _exit(127);
    }
    if(pid < 0) return -1;
    *child = pid;
    return master;
}
```

### ৭.৩ VT100/ANSI পার্সার
`shell/terminal/vt.c` এ ESC sequence, cursor move, erase, SGR, alternate screen, scrollback বাস্তবায়ন করতে হবে।

### ৭.৪ nilshell মূল পরিবর্তন
`shell/nilshell.c` থেকে "sleep loop" সরিয়ে নিচের মত ফ্লো করতে হবে:

1. NilHAL init
2. NilUI server init (`nilui_server_start`)
3. SoftBus init (`nil_softbus_init`)
4. Terminal backend init (PTY master open)
5. Compositor scene তৈরি (terminal window + status + launcher integration)
6. Input routing (keyboard/IM) টার্মিনালে ফরওয়ার্ড
7. Render loop (DRM/KMS + nilui-gpu)
8. Event loop (epoll) - PTY read, input events, UI events

**সতর্কতা:** "ps/services/net output fabricated" যা README বলে সেটি পুরোপুরি অপসারণ করতে হবে। `ps` চাইলে `/proc` পড়বে, `netstat/ip` চাইলে `netlink`/`/proc/net/*` পড়বে, `services` চাইলে nilinit/supervisor স্টেট (বাস্তব) দেখাবে।

## ৮. নিলব্রাউজার (NilBrowser) কে বাস্তব ব্রাউজার বানানো

লক্ষ্য: **UI শেল এ সত্যিকারের ওয়েব ব্রাউজিং সম্ভব করা**। সম্পূর্ণ নিজস্ব ইঞ্জিন একসাথে বানানো কঠিন, তাই প্রকল্প নীতির সাথে সামঞ্জস্য রেখে **বাস্তব রেন্ডারিং ব্যাকেন্ড** সংযুক্ত করা।

### ৮.১ পথ নির্ধারণ
`apps/browser/` ও `apps/nilbrowser/` দুটো আছে। একটিকে canonical করে অন্যটা এডাপ্টার হিসেবে ব্যবহার করা।

### ৮.২ বাস্তব ইঞ্জিন সংযুক্তি (প্রস্তাবিত)
প্রজেক্টে `WPE WebKit` / `MiniBrowser` স্টাইল বা `WebKitGTK` এর মডিউলার অংশ ব্যবহার বিবেচনা করা যেতে পারে। তবে সব কিছু বাইনারি ডাউনলোড নয়, সোর্স ভিত্তিক ইন্টিগ্রেশন।

`apps/nilbrowser/Cargo.toml` এ যোগ:

```toml
[dependencies]
wpewebkit-sys = { version = "...", optional = true } # বা custom nil-wpe binding
glib = { version = "0.18", features = ["v2_70"] }
```

যদি বিল্ড env তে `libwpe`, `wpebackend-fdo`, `libwpewebkit` না থাকে, তবে বিল্ড টাইমে স্পষ্ট এরর দেখিয়ে বলবে কী ইন্সটল করতে হবে। **কোনো HTML জেনারেট করে "fake page" দেখানো যাবে না।**

### ৮.৩ বাস্তব বাস্তবায়ন ধাপ
1. `apps/nilbrowser/src/engine.rs` তৈরি - WPE view create, load_uri, navigation, history
2. `apps/nilbrowser/src/ui.rs` - NilUI/Alap UI (address bar, tabs, back/forward/reload)
3. `apps/nilbrowser/src/ipc.rs` - nilbus এর মাধ্যমে নেটওয়ার্ক/সিকিউরিটি ইভেন্ট
4. Input (touch/keyboard) WPE এ ফরওয়ার্ড
5. Compositing - texture/WPE drawable -> NilUI-GPU surface
6. Cookies/Cache - `~/.local/share/nilbrowser/` এ বাস্তব স্টোরেজ
7. JS/Network - বাস্তব

### ৮.৪ Fallback নিষিদ্ধ
`README` বলেছে "[SIMULATED]" - এই ট্যাগের কোড সম্পূর্ণ মুছে ফেলতে হবে। `if webview_unavailable { show_placeholder }` এর বদলে `if engine_init_failed { eprintln!("FATAL: nilbrowser requires real web engine"); std::process::exit(1); }`

### ১২.১ Sandbox

## ১৩. SoftBus (nilbus) বাস্তব নেটওয়ার্কিং দিয়ে সম্পন্ন করা

ফাইল: `softbus/src/main.rs`, `softbus/src/quic.rs`, `softbus/src/mdns.rs`, `softbus/src/ctl.rs`

**করণীয়:**

1. **mDNS**: `avahi` নয়, নিজের বাস্তব mDNS responder/querier (RFC 6762 ভিত্তিক) - `mdns.rs` এ বাস্তব implementation চালু
2. **QUIC**: `quinn` দিয়ে TLS 1.3, আলাদা সার্ট ইস্যু (CA নয়, self-signed হলেও key rotation চিন্তা)
3. **Control socket**: `/run/nilos/bus.sock` Unix domain socket, peer credentials যাচাই
4. **Peer discovery UI**: `apps/settings` বা shell এ "simulated peer list" মুছে বাস্তব ডিভাইস দেখানো

**সতর্কতা:** `nilbus` ইতিমধ্যেই অনেকাংশে বাস্তব। শুধু UI তে সিমুলেটেড তালিকা থাকলে সেটা সরাতে হবে।

## ১৭. যাচাইকরণ (Verification) ধাপসমূহ

প্রত্যেক ধাপের শেষে নিচের যাচাই করতে হবে।

### ১৭.১ বিল্ড যাচাই
```bash
cargo test --workspace 2>&1 | tail -30
cargo clippy --workspace -- -D warnings 2>&1 | tail -20
cargo build --workspace --release
```

### ১৭.২ QEMU বুট যাচাই
QEMU তে বুট করার পর চেক:

- [ ] `dmesg` এ কোন `nilhal fake`, `simulated service` এর গুরুতর লোগ নেই
- [ ] `ps aux` বা `/proc/1/cmdline` -> `nilinit`
- [ ] `/run/nilos/` এ সকার্ট/সকেট আছে
- [ ] `nilshell` খুললে সত্যিকারের PTY শেল পাওয়া যায় (`echo $$`, `pwd`, `cat /proc/version`)
- [ ] `ps`, `ls /proc`, `cat /sys/class/power_supply/*/capacity` বাস্তব ডাটা
- [ ] DRM/KMS এ GUI রেন্ডার
- [ ] evdev ইনপুট কাজ

### ১৭.৩ সার্ভিস যাচাই

```bash
# nilbus üzerinden বা log
journalctl-like বা /var/log/nilos/* নয়, supervisor log
# nilinit log থেকে সার্ভিস স্টেট দেখা
```

- [ ] `nild`, `netd`, `powerd`, `audiod`, `inputd` বাস্তব মোডে RUNNING
- [ ] হার্ডওয়্যার ছাড়া যেই সার্ভিস বাধ্যতামূলক না, তাদের স্টেট পরিষ্কার

### ১৭.৪ nilpkg যাচাই
```bash
# test install
nilpkg keygen
nilpkg pack ./test-app --out test.nilax
nilpkg sign test.nilax --key ./key.priv

```

সাইনেচার ভেরিফাই, আর্ক চেক, পারমিশন চেক সকলটা বাস্তব হতে হবে।

### ১৭.৫ ব্রাউজার যাচাই
NilBrowser খুলে `about:blank` না, প্রকৃত URI লোড করতে পারলে সফল। কোন ফেইক HTML রেন্ডার না।

### ১৭.৬ টার্মিনাল যাচাই
nilshell এ `top`, `cat /proc/meminfo`, `ip link`, `mount` চালালে বাস্তব আউটপুট আসতে হবে। পূর্বের "fabricated" আউটপুট সম্পূর্ণ চলে যাওয়া চাই।

### ১৭.৭ অ্যান্ড্রয়েড ব্রিজ যাচাই
রুটফস না থাকলে ব্রিজ বন্ধ থাকবে, রুটফস থাকলে আইসোলেটেড নেমস্পেসে শুরু হবে। Native UI থেকে পৃথক।
