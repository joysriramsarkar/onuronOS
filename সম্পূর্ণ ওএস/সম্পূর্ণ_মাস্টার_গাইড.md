# অনুরণ ওএস — সম্পূর্ণ মাস্টার গাইড: বুট থেকে অ্যাপ, ব্রাউজার, টার্মিনাল, অ্যান্ড্রয়েড ব্রিজ (শূন্য স্টাব)

> **এক ফাইলে সবকিছু:** বুটলোডার → কার্নেল → initramfs → nilinit (PID 1) → NilHAL → ডেমন → কম্পোজিটর → nilrt স্যান্ডবক্স → nilpkg → NilLang/Alap/NilUI → সব নেটিভ অ্যাপ → ব্রাউজার → টার্মিনাল → অ্যান্ড্রয়েড ব্রিজ → রিয়েল মোবাইল (OnePlus 6T `fajita`) ফ্ল্যাশ ও ব্রিং-আপ।
>
> Official ecosystem: **"Onuron OS — powered by NilLang + Alap"** · Kernel: Linux LTS 6.6 · Userspace: Rust-first · Apps: `.nil` / signed `.nilax` · Android: isolated LXC container (কখনোই host identity নয়)।
>
> **প্রকাশ:** v1.0 · তারিখ: ২০২৬-১০ · মেইন্টেইনার ডকুমেন্ট — `AGENTS.md`-এর সব স্থাপত্য-নিয়ম মেনে লেখা।

## ০. জিরো-স্টাব চুক্তি (এই ডকুমেন্টের আইন)

এই গাইডে "চলবে" বলতে কোনো নকল বা ভান করা বোঝায় না।

1. **কোনো `[SIMULATED]` ব্যাজ, demo value, বা fabricated output নয়।** হার্ডওয়্যার না থাকলে সংশ্লিষ্ট সার্ভিস `failed` স্টেটে যাবে এবং UI পরিষ্কার এরর দেখাবে — ভান করবে না।
2. **প্রতিটি ডেমন বাস্তব কার্নেল ইন্টারফেসে কথা বলবে:** sysfs, evdev, netlink, ALSA, V4L2, DRM/KMS, binder — `ioctl`/সিসকল দিয়ে, hard-code করা স্ট্রিং দিয়ে নয়।
3. **FakeHAL / nilsim শুধু CI ও desktop dev-এর জন্য**; রিলিজ ইমেজে `sim-fallback` feature compile-time-এ বন্ধ।
4. **Android compatibility একটি যন্ত্রণাহীন গেস্ট কনটেইনার** — OnuronOS-এর নেটিভ পরিচয় (nilinit/NilHAL/nilrt/NilLang/Alap/NilUI/`.nilax`/nilpkg/nilshell/SoftBus) অটুট।
5. **সব IPC `nilprotocol` ফ্রেমে:** `ONUR` magic + versioned header + ≤1 MiB payload।
6. **প্রতিটি নেটিভ অ্যাপ signed `.nilax`**, `nilrt` দিয়ে launch: namespaces + seccomp BPF + SELinux enforcing + প্রতি-অ্যাপ আলাদা UID।
7. **Verified boot (AVB 2.0) + dm-verity + A/B স্লট + signed OTA** — unsigned ইমেজ বুট হয় না।

### ০.১ সততা দায়বদ্ধতা (AGENTS.md নিয়ম ৪)

এই ডকুমেন্ট একটি **সম্পূর্ণ নির্মাণ-নির্দেশনা (build specification)**। প্রতিটি অধ্যায়ের শেষে সেই সাবসিস্টেমের বর্তমান বাস্তব অবস্থা একটা করে ম্যাচিউরিটি ট্যাগে দেওয়া আছে:

| ট্যাগ | অর্থ |
|---|---|
| 🟢 `IMPLEMENTED` | কোড আছে, টেস্ট আছে, ডিভাইসে প্রমাণিত |
| 🔵 `FUNCTIONAL PROTOTYPE` | QEMU/prototype-এ কাজ করে |
| 🟡 `EXPERIMENTAL` | আংশিক/চলমান |
| 🔴 `PLANNED` | এই ডকুমেন্টে নকশা দেওয়া, ইমপ্লিমেন্টেশন বাকি |

এই নির্দেশনা অনুসরণ করে কোড লিখলেই উপরের সারির ট্যাগ 🟢 হবে — কিন্তু "ডকুমেন্টে লেখা আছে" মানেই "ইমপ্লিমেন্টেড" নয়। চূড়ান্ত অধ্যায়ে (§২৪) একটি সৎ reality ledger আছে।

## ১. সম্পূর্ণ সিস্টেম ম্যাপ (এক নজরে)

```
┌──────────────────────────────────────────────────────────────────────────┐
│ STAGE-0  SoC BootROM → XBL/ABL (fajita) বা U-Boot (dev boards)           │
│          → AVB 2.0 verify (boot_a/boot_b + vbmeta) → slot select         │
├──────────────────────────────────────────────────────────────────────────┤
│ STAGE-1  Linux LTS 6.6 (Image.gz + sdm845-oneplus-fajita.dtb)            │
│          → initramfs: dm-verity mount → switch_root                      │
├──────────────────────────────────────────────────────────────────────────┤
│ STAGE-2  nilinit (PID 1, Rust)                                           │
│          → /proc /sys /dev /run mount → cgroups v2 → SELinux load        │
│          → fscrypt unlock /data → service TOML scan → supervisor spawn   │
├──────────────────────────────────────────────────────────────────────────┤
│ STAGE-3  Core daemons (socket-activated, supervised):                    │
│   logd → nild → netd → dnsd → ntpd → powerd → thermald → inputd →        │
│   audiod → camerad → telephonyd → btd → notifyd → nilkeyd → authd →      │
│   clipd → alarmd → vpnd → backupd → nilupd → nilwdt → mediad → userd →   │
│   nilstore → crashd → nilperf → niltrace → nilsr → nilttsd → nilimed →   │
│   nilandroidd → softbusd                                                  │
├──────────────────────────────────────────────────────────────────────────┤
│ STAGE-4  nilui-gpu (DRM/KMS compositor) → nilshell (NilUI scene)         │
│          → lockscreen (PIN, Argon2/stretched-hash) → launcher            │
├──────────────────────────────────────────────────────────────────────────┤
│ STAGE-5  Apps (সব signed .nilax, nilrt launch):                           │
│   launcher lockscreen oobe phone messages camera files settings music    │
│   notes calculator clockwidget wifi bluetooth display sound security     │
│   language a11y vpn backup storage sysupdate nilbrowser terminal(android) │
├──────────────────────────────────────────────────────────────────────────┤
│ STAGE-6  Android guest (LXC): SurfaceFlinger→wl_surface, binder, APK     │
└──────────────────────────────────────────────────────────────────────────┘
```

**ডেটা নীতি:** অ্যাপ কখনো হার্ডওয়্যার সরাসরি খোলে না। অ্যাপ → `nilprotocol` IPC → ডেমন → NilHAL → kernel। শুধু কম্পোজিটর ও ডেমনেরাই `/dev` স্পর্শ করে।

## ৪. বুটলোডার ও ভেরিফায়েড বুট (AVB 2.0 + A/B)

### ৪.১ বুট চেইন নিরাপত্তা মডেল

```
BootROM (eFuse-এ PPK hash) → XBL verify ABL/SBL → ABL verify boot_? (vbmeta)
→ kernel verify initramfs (dm-verity root hash, vbmeta-তে signed)
→ nilinit verify /system (dm-verity) ও প্রতিটি .nilax (Ed25519)
```

কোনো ধাপ fail হলে: A/B স্লটের অন্যটিতে করবে `nilupd`/bootloader (`slot_unbootable` মার্ক করে)। পরপর ৩ বার বুট ব্যর্থ হলে `recovery` স্লট।

### ৪.২ `boot.cmd` (U-Boot dev-board পাথ)

```sh
setenv bootargs "console=ttyMSM0,115200 earlycon root=/dev/dm-0 ro rootwait \
  dm=\"system none ro,0 1 verity 1 /dev/sda15 /dev/sda15 4096 4096 262144 262144 \
  sha256 ${verity_root_hash} ${verity_salt}\" \
  androidboot.selinux=enforcing androidboot.verifiedbootstate=orange \
  onuron.slot_suffix=${slot_suffix} panic=30"
part uuid mmc 0:system_a uuid_a
part uuid mmc 0:system_b uuid_b
ab_select slot mmc 0:2#misc
avb verify 0 ${slot}${avb_boot_part} ${fdt_addr_r}
bootm ${kernel_addr_r} ${ramdisk_addr_r} ${fdt_addr_r}
```

### ৪.৩ vbmeta সাইনিং (real Ed25519 — রেপোর `tools/mkvbmeta` ব্যবহার)

```bash
# ১) ডিভাইসস্পেসিফিক সাইনিং কী তৈরি (শুধু release signing host-এ, HSM রাখো)
openssl genpkey -algorithm ed25519 -out onuron_release_pk.pem

# ২) boot.img + system erofs hash tree + vbmeta
avbtool make_vbmeta_image \
  --key onuron_release_pk.pem --algorithm SHA256_RSA4096 \
  --chain_partition boot:1:cert_boot.x509.pem \
  --include_descriptors_from_image out/oneplus-fajita/boot.img \
  --include_descriptors_from_image out/oneplus-fajita/system.img \
  --rollback_index 7 --output out/oneplus-fajita/vbmeta.img

# ৩) ফ্ল্যাশ (verified boot চালু অবস্থায়)
fastboot --disable-verity flash vbmeta out/oneplus-fajita/vbmeta.img
fastboot flash boot_a out/oneplus-fajita/boot.img
```

**নিয়ম:** রিলিজ সাইকেলে `--set_verification_disabled` কখনোই নয়। Development-এ `orange` state (রিস্ক সহ) মেনে নেওয়া যায়; production `green`।

## ৫. initramfs — fail-loud, verified root switch

`build/mkinitramfs.py` তৈরি করে `nilos-initramfs.cpio.gz`। ভেতরে: `toybox` (static), `nilverity` (dm-verity setup helper), slot logic। কোনো silent fallback নেই — ভুল slot/hash হলে recovery-তে পড়ে।

### ৫.১ `/init` (initramfs)

```sh
#!/bin/sh
export PATH=/bin:/sbin:/usr/bin
toybox mount -t proc none /proc
toybox mount -t sysfs none /sys
toybox mount -t devtmpfs none /dev

# --- A/B স্লট সিলেক্ট (bootloader cmdline থেকে) ---
SLOT=$(tr ' ' '\n' </proc/cmdline | grep '^onuron.slot_suffix=' | cut -d= -f2)
[ "$SLOT" = "b" ] && SYSPART=/dev/sda16 || SYSPART=/dev/sda15

# --- dm-verity আনলক (root hash vbmeta descriptor থেকে পার্স করা) ---
ROOT_HASH=$(nilverity read-hash /dev/sda17)   # vbmeta partition
[ -z "$ROOT_HASH" ] && exec /bin/nilrecovery "vbmeta: root hash missing"

nilverity open "$SYSPART" system "$ROOT_HASH" || exec /bin/nilrecovery "verity failed"
toybox mkdir -p /newroot
toybox mount -o ro /dev/mapper/system /newroot || exec /bin/nilrecovery "mount failed"

# --- switch_root ---
toybox umount /proc /sys /dev
exec toybox switch_root /newroot /usr/bin/nilinit
```

### ৫.২ `nilrecovery` আচরণ

- কারণ স্ক্রিনে দেখায় (`verity failed`, `vbmeta invalid`, slot `unbootable`)।
- USB gadget-এ `fastboot` expose করে (`nilfastbootd`, `runtime/nilrt/src/bin/nilfastbootd.rs`) যাতে ডিভাইস পুনরুদ্ধার যায় — কোনো "ব্রিক" অবস্থা নেই।

**ম্যাচিউরিটি:** 🔵 FUNCTIONAL PROTOTYPE (QEMU পাথ প্রমাণিত; fajita partition map ডিভাইসে যাচাই করতে হবে)।

## ৬. nilinit — PID 1 (সম্পূর্ণ প্রোডাকশন ফ্লো)

`nilinit/src/main.rs` + `supervisor.rs` + `activate.rs` + `recovery.rs` + `fscrypt.rs`। নিচে লজিক্যাল কমপ্লিট স্ট্রাকচার — প্রতিটি ধাপ বাস্তব সিসকল:

```rust
// nilinit/src/main.rs — PID 1 entry, প্রকৃত বুট পাথ
use nix::sys::reboot::{reboot, RebootMode};
use nix::unistd::Pid;
use std::path::Path;

mod supervisor;
mod activate;
mod recovery;
mod fscrypt;

fn main() {
    assert_eq!(nix::unistd::getpid(), Pid::from_raw(1), "nilinit must run as PID 1");

    // ── ধাপ ১: ভার্চুয়াল ফাইলসিস্টেম (বাস্তব mount(2) কল) ─────────────────
    mount("proc",     "/proc", "proc",     MS_NOSUID | MS_NOEXEC | MS_NODEV)?;
    mount("sysfs",    "/sys",  "sysfs",    MS_NOSUID | MS_NOEXEC | MS_NODEV)?;
    mount("devtmpfs", "/dev",  "devtmpfs", MS_NOSUID)?;
    mount("run",      "/run",  "tmpfs",    MS_NOSUID | MS_NODEV)?;
    mount("cgroup2",  "/sys/fs/cgroup", "cgroup2", MS_NOSUID | MS_NOEXEC | MS_NODEV)?;
    std::fs::create_dir_all("/run/nilos")?;          // IPC socket ডিরেক্টরি
    std::fs::create_dir_all("/dev/binderfs")?;

    // ── ধাপ ২: SELinux enforcing ──────────────────────────────────────────
    selinux::load_policy("/etc/selinux/onuron/policy/policy.33")?;
    selinux::set_enforce(true)?;                     // permissive নয় — কখনোই নয়

    // ── ধাপ ৩: পার্সিস্টেন্ট স্টোরেজ (fscrypt unlock + /data mount) ──────
    fscrypt::mount_and_unlock("/dev/sda21", "/data")?;  // keyring: nilkeyd key
    std::fs::create_dir_all("/data/app")?;
    std::fs::create_dir_all("/data/system")?;
    std::fs::create_dir_all("/data/config")?;

    // ── ধাপ ৪: ওয়াচডগ আর্ম (হ্যাং হলে hardware reset) ────────────────────
    let wdt = nilwdt::arm("/dev/watchdog", /*timeout_secs=*/ 15)?;

    // ── ধাপ ৫: সার্ভিস টেবিল লোড + socket activation sockets bind ────────
    let table = ServiceTable::load_dir("/etc/nilos/services")?;   // *.toml
    let activated = activate::bind_all(&table)?;       // pre-bind /run/nilos/*.sock

    // ── ধাপ ৬: সুপারভাইজর — dependency order-এ spawn, restart policy ─────
    let mut sup = supervisor::Supervisor::new(table, activated);
    sup.boot()?;                                       // logd → nild → প্রকৃত গ্রাফ

    // ── ধাপ ৭: PID-1 reaper + সিগন্যাল মাল্টিপ্লেক্স (চিরকালীন লুপ) ───────
    loop {
        match sup.poll_event() {
            Event::ChildExited(pid, code) => sup.on_exit(pid, code),
            Event::WatchdogTick => wdt.feed(),
            Event::SigTerm => { sup.stop_all(); reboot(RebootMode::RB_POWER_OFF).ok(); }
            Event::SigChld => sup.reap(),
            Event::ServiceCrashed(3) => recovery::maybe_enter(&sup), // ৩ crash → recovery
        }
    }
}
```

```rust
// runtime/nilhal/src/backends/linux.rs — ব্যাটারি (খণ্ডিত উদাহরণ)
impl PowerHal for LinuxPower {
    fn battery_percent(&self) -> Result<u8, HalError> {
        // /sys/class/power_supply/<BAT>/capacity প্রকৃত পড়া
        let bat = find_battery()?;                    // স্ক্যান: type == "Battery"
        let s = std::fs::read_to_string(bat.join("capacity"))?;
        s.trim().parse().map_err(|_| HalError::CorruptSysfs)
    }
    fn set_screen_brightness(&self, v: u8) -> Result<(), HalError> {
        let bl = Path::new("/sys/class/backlight/panel0-backlight");
        let max: u32 = std::fs::read_to_string(bl.join("max_brightness"))?.trim().parse()?;
        std::fs::write(bl.join("brightness"), ((v as u32 * max) / 255).to_string())?;
        Ok(())
    }
}
```

## ৯. সিস্টেম ডেমন — প্রতিটির রিয়েল ব্যাকএন্ড বাইন্ডিং

### ৯.০ নিয়ম (সব ডেমনে প্রযোজ্য)

- প্রতিটি ডেমনের socket: `/run/nilos/<name>.sock`, ফ্রেম: `nilprotocol` (ONUR magic, version, ≤1MiB)।

### ৯.১ netd + dnsd + ntpd (নেটওয়ার্ক স্ট্যাক)

- **netd:** nl80211 netlink → `wpa_supplicant` (`/run/wpa_supplicant/wlan0` ctrl socket) পরিচালনা; DHCP `dhcpcd`-এর বদলে নিজস্ব minimal client (`services/netd/src/dhcp.rs`). SSID স্ক্যান, WPA3-SAE, mdot11r।
- **dnsd:** `/etc/resolv.conf` লেখেনি — নিজস্ব stub resolver (DNS-over-TLS 853 → upstream 1.1.1.1/8.8.8.8), cache + negative cache।
- **ntpd:** SNTP (UDP/123), RTC-তে `rtc_set_time` ioctl, step নয় শুধু slew।

```rust
pub fn scan(&self, iface: u32) -> Result<Vec<ScanResult>> {
    let sock = Nl80211Socket::connect()?;

    let done = sock.wait_event(EVT_SCAN_DONE, Duration::from_secs(10))?;

}
```

### ৯.৭ btd (Bluetooth — BlueZ D-Bus)

- BlueZ স্ট্যাক (`bluetoothd`) সিস্টেমে embedded; `btd` Rust D-Bus client → `org.bluez.Adapter1`/`Device1`।

### ৯.৮ নিরাপত্তা ও ডেটা ডেমন

- **nilkeyd:** kernel keyring (`KEY_SPEC_SESSION_KEYRING`) + fscrypt মাস্টার-কী; `add_key`/`keyctl` সিসকল; restart nirvana না — কী memory-মাত্র, ডিস্কে sealed blob।

- **backupd:** F2FS/ext4 snapshot → rsync-সদৃশ delta to SoftBus peer/SD; encrypted (XChaCha20-Poly1305)।
- **nilupd:** A/B OTA — §২০।
- **crashd:** `pstore`/ramoops parse, minidump আপলোড (consent-gated, telemetry নয়)।
- **mediad:** মিডিয়া স্ক্যান (`/data/music`, `/data/dcim`), metadata index (SQLite)।
- **clipd:** clipboard, স্কোপড পারমিশন (`nilrt` broker দিয়ে)।
- **alarmd:** RTC wakealarm (`/sys/class/rtc/rtc0/wakealarm`)।
- **userd/nilstore:** অ্যাকাউন্ট, settings DB (`/data/system/*.db`, atomic writes)।
- **notifyd:** `/data/notifications/` persistent জার্নাল + ওয়েক লক সম্মান।
- **nilperf/niltrace:** প্রকৃত perf events + ftrace (`/sys/kernel/debug/tracing`) — shipping build-এ অফ, diagnostics-এ অন।
- **nilsr:** SoftBus daemon glue (mDNS + QUIC, §১৮)।
- **nilttsd:** TTS — Piper-সদৃশ on-device ONNX বা eSpeak-NG; কোনো ক্লাউড কল নয়।
- **nilimed:** ইনপুট মেথড (ভার্চুয়াল কীবোর্ড layout engine, বাংলা+ইংরেজি)।
- **nild:** সার্ভিস ডিরেক্টরি (নাম→socket রেজোলভার; `nilbus` ডিসকভারি)।
- **logd:** প্রকৃত `/dev/kmsg` + জার্নাল `/data/log/` (ring, zstd)।

**ম্যাচিউরিটি:** ডেমন কোরগুলো 🔵 (QEMU) — modem/camera/audio-র on-device অংশ সম্পন্ন না হলে ইচ্ছাকৃতভাবে 🟡।

## ১০. nilrt — প্রতি-অ্যাপ আইসোলেশন (চালুর আগে যা ঘটে)

প্রতিটি `.nilax` চালু: `nilrt-launch <app>` →

```rust
// runtime/nilrt/src/sandbox.rs — বাস্তব স্যান্ডবক্স স্ট্যাক
pub fn enter_sandbox(app: &AppManifest) -> Result<(), SandboxError> {
    // ১) Namespaces: প্রকৃত unshare(2)
    unshare(CLONE_NEWNS | CLONE_NEWIPC | CLONE_NEWUTS | CLONE_NEWPID)?;

    // ২) Mount প্রিভেট + minimal root: /system ro bind, /data/app/<id> rw, tmpfs /tmp
    mount(NULL, "/", NULL, MS_REC | MS_PRIVATE)?;
    bind_ro("/system", "/system")?;
    bind_rw(&app.data_dir, "/data")?;                 // শুধু নিজের ডেটা
    mount("tmpfs", "/tmp", "tmpfs", MS_NOSUID | MS_NODEV | MS_NOEXEC)?;

    // ৩) UID/GID: প্রতি অ্যাপ আলাদা (AID_BASE=10000+)
    setgid(app.gid)?; setuid(app.uid)?;
    prctl(PR_SET_NO_NEW_PRIVS, 1, 0, 0, 0)?;

    // ৪) Seccomp BPF: allowlist (~110 syscall) — প্রকৃত prctl ফিল্টার
    seccomp::install_profile(&app.seccomp_profile)?;  // seccomp_data + BPF_PROG_LOAD

    // ৫) SELinux ডোমেইন ট্রানজিশন: onuron_app_t (policy §১৯.১)
    selinux::execcon(&format!("u:r:onuron_app_{}_t:s0", app.id))?;

    // ৬) cgroup v2: memory.max/cpu.max/io.max — প্রকৃত ফাইল রাইট
    cgroup::join(&app.id, Limits { mem: "256M", cpu: "200000 100000" })?;
    Ok(())
}
```

পারমিশন (ক্যামেরা/মাইক/SMS/লোকেশন): `nilrt::permbroker` — UI prompt, JSON grant store (৭ দিনের auto-revoke), atomic write + corrupt quarantine। অ্যাপ সরাসরি `/dev/video0` খুলতে গেলে SELinux denial + broker prompt।

**ম্যাচিউরিটি:** 🔵 FUNCTIONAL PROTOTYPE (sandbox+seccomp+broker প্রমাণিত)।

```rust
// pkg/nilpkg/src/verify.rs — ইনস্টলের আগে প্রকৃত যাচাই
pub fn verify_nilax(path: &Path) -> Result<VerifiedManifest, PkgError> {
    let blob = std::fs::read(path)?;
    let (manifest, payload, signature, pubkey_id) = parse_nilax(&blob)?; // header: NILAX1
    let key = keystore::trusted_key(pubkey_id)?             // /system/etc/nilpkg/trust/
        .ok_or(PkgError::UnknownSigner)?;                   // অজানা সাইনার → ব্যর্থ
    let digest = blake3::hash(&[manifest, payload].concat());
    key.verify(digest.as_bytes(), &signature).map_err(|_| PkgError::BadSignature)?;
    Ok(manifest)    // তারপরেই জার্নাল: install.begin → unpack → verify hashes → commit
}
```

Rollback: `install` জার্নাল ফাইল `/data/system/nilpkg/journal/<id>` — বিদ্যুৎ বিভ্রাটে পরবর্তী বুটে `nilpkg recover`।

**ম্যাচিউরিটি:** 🔵 FUNCTIONAL PROTOTYPE (সাইন/জার্নাল/লক প্রমাণিত)।

## ১৬. টার্মিনাল — রিয়েল PTY (nilterminal)

স্ক্রিনের টার্মিনাল কখনোই লিখিত স্ট্রিং দেখাবে না। এটি প্রকৃত `openpty(3)` + `fork` + `execve("/bin/sh")` করে — rootfs-এ **toybox** শিপ করা (শেল + coreutils)।

### ১৬.১ PTY ইঞ্জিন

```rust
// apps/terminal/src/pty.rs — প্রকৃত পসিক্স PTY সেশন
use libc::{self, c_int};
use std::{fs::File, os::unix::io::FromRawFd};

pub struct PtySession { master: File, child: c_int, pub scrollback: RingBuf }

impl PtySession {
    pub fn spawn(shell: &str, cols: u16, rows: u16) -> Result<Self, PtyError> {
        let ws = libc::winsize { ws_row: rows, ws_col: cols, ws_xpixel: 0, ws_ypixel: 0 };
        let mut master: c_int = -1;
        let mut slave:  c_int = -1;
        let rc = unsafe { libc::openpty(&mut master, &mut slave, std::ptr::null_mut(),
                                        std::ptr::null_mut(), &ws) };
        if rc != 0 { return Err(PtyError::Alloc); }
        match unsafe { libc::fork() } {
            0 => unsafe {                                   // child
                libc::close(master);
                libc::setsid();
                libc::ioctl(slave, libc::TIOCSCTTY, 0);
                libc::dup2(slave, 0); libc::dup2(slave, 1); libc::dup2(slave, 2);
                libc::close(slave);
                std::env::set_var("TERM", "xterm-256color");
                std::env::set_var("HOME", "/data/home");
                std::env::set_var("PATH", "/system/bin:/system/xbin");
                let sh = std::ffi::CString::new(shell).unwrap();
                libc::execvp(sh.as_ptr(), [sh.as_ptr(), std::ptr::null()].as_ptr());
                libc::_exit(127);
            },
            pid if pid > 0 => {
                unsafe { libc::close(slave); }
                set_nonblock(master)?;
                Ok(Self { master: unsafe { File::from_raw_fd(master) },
                          child: pid, scrollback: RingBuf::new(64 * 1024) })
            }
            _ => Err(PtyError::Fork),
        }
    }
    pub fn write(&mut self, bytes: &[u8]) -> std::io::Result<()> { use std::io::Write; self.master.write_all(bytes) }
    pub fn read(&mut self, buf: &mut [u8]) -> std::io::Result<usize> { use std::io::Read; self.master.read(buf) }
    pub fn resize(&mut self, cols: u16, rows: u16) {          // TIOCSWINSZ — মোবাইল রোটেশনে জরুরি
        let ws = libc::winsize { ws_row: rows, ws_col: cols, ws_xpixel: 0, ws_ypixel: 0 };
        unsafe { libc::ioctl(self.master.as_raw_fd(), libc::TIOCSWINSZ, &ws); }
    }
}
```

## ১৭. অ্যান্ড্রয়েড ব্রিজ — বাস্তব LXC গেস্ট (কোনো placeholder নয়)

নীতি: অ্যান্ড্রয়েড একটি **গেস্ট কন্টেইনার**, হোস্ট পরিচয় নয় (AGENTS.md §২)। Waydroid-মডেলের শেয়ার্ড-কার্নেল LXC — হোস্ট কার্নেলই binder/binderfs দেয় (§৩.৩), গেস্টে AOSP Android 14 GSI রান করে।

### ১৭.১ হোস্ট ডেমন: `nilandroidd`

```rust
// services/nilandroidd/src/main.rs — বাস্তব কন্টেইনার লঞ্চ (সংক্ষিপ্ত)
fn main() -> Result<()> {
    // ১) binderfs mount + হোস্ট proxy
    fs::create_dir_all("/dev/binderfs")?;
    mount("binder", "/dev/binderfs", "binder", 0)?;
    symlink("/dev/binderfs/binder", "/dev/binder")?;

    // ২) cgroup v2 সীমা (গেস্ট যেন হোস্টকে শ্বাসরোধ না করে)
    cgroup_set("/sys/fs/cgroup/android", "memory.max", "1536M")?;
    cgroup_set("/sys/fs/cgroup/android", "pids.max", "512")?;

    // ৩) GSI পার্টিশন যাচাই (dm-verity protected, ro)
    mount_ro_verified("/dev/mapper/android_system", "/var/lib/onuron/android/system")?;

    // ৪) LXC launch
    let st = Command::new("lxc-start")
        .args(["-n", "onuron-android", "-d", "-f", "/etc/nilos/lxc/android.conf"])
        .status()?;
    if !st.success() { return Err(err("container start failed")); }   // fail-loud, ভান নেই

    // ৫) গেস্ট এজেন্টের জন্য অপেক্ষা + অ্যাপ-তালিকা সার্ভিস
    wait_socket("/run/nilos/android-agent.sock", Duration::from_secs(30))?;
    serve_app_list("/run/nilos/android-apps.sock")?;
    Ok(())
}
```

## ২০. nilupd — সাইনড A/B OTA

```
ডাউনলোড payload (এইচটিটিপিএস, resume-যোগ্য) → verify Ed25519 (vbmeta keyring)
→ অন্য স্লটে লিখো (boot_b + system_b) → vbmeta_b আপডেট → bootloader-এ slot=B সেট
→ রিবুট → বুট সফল হলে mark_boot_successful, না হলে ৩ বার পর অটো-রোলব্যাক A তে
```

- **ডেল্টা আপডেট:** bsdiff payload (v2)।
- **রোলব্যাক সুরক্ষা:** vbmeta `rollback_index` — পুরনো সাইনড ইমেজ রিজেক্ট।
- `sysupdate` অ্যাপ = nilupd-এর UI (চেক/ডাউনলোড/প্রগ্রেস/রিবুট)।

**ম্যাচিউরিটি:** 🟡 EXPERIMENTAL (মেকানিজম নকশা সম্পূর্ণ; ডিভাইসে দুই-স্লট প্রমাণ বাকি)।

6. **nilinit স্টেজ:** সব ডেমন `active` (`svc list`), crash নেই (`crashd list` খালি) ✓
7. **শেল:** lockscreen → PIN → launcher ✓

### ২১.৩ মডেম ব্রিং-আপ (সবচেয়ে কঠিন অংশ — সৎভাবে)

QMI স্ট্যাকের আগে এই userspace সহায়কগুলো বাধ্যতামূলক (vendor blob সার্ভ):

```bash
# system ডেমন হিসেবে (nilinit TOML)
/usr/bin/tqftpserv        # modem ফার্মওয়্যার ফাইল সার্ভ করে
/usr/bin/pd-mapper        # QMI সার্ভিস ডিসকভারি
/usr/bin/rmtfs            # modem FS (efs) ব্যাকিং স্টোর
# তারপর: qrtr-ns চালু → telephonyd QMI attach → netd wwan iface
```

ভয়েস কল অডিও: ADSP (`q6voiced`-সদৃশ দেমন) — এই অংশ সম্পন্ন না হলে ফোন অ্যাপ **"কল: অপ্রস্তুত (EXPERIMENTAL)"** দেখাবে, ভান করবে না।

### ২১.৪ ক্যামেরা ব্রিং-আপ

mainline SDM845-এ ক্যামেরা = `libcamera` pipeline (sensor driver: IMX519/S5K3M5 vendor dtb)। না চললে camerad `Err(NoSensor)` — ক্যামেরা অ্যাপ সৎ এরর দেখায়।

### ২১.৫ অডিও/ব্যাটারি/থার্মাল

- ALSA UCM2 প্রোফাইল: `/usr/share/alsa/ucm2/sdm845/fajita.conf` (Speaker/Earpiece/HS/BT)।
- ব্যাটারি: `bq27xxx` fuel gauge + SMB2 charger — powerd সরাসরি পড়ে।
- থার্মাল: `tsens` জোন → thermald (§৯.২)।

## ২২. এন্ড-টু-এন্ড বিল্ড ও ফ্ল্যাশ (এক জায়গায় সব কমান্ড)

```bash
# ── ১) ইউজারস্পেস (রিলিজ, sim-fallback OFF) ──────────────────────────────
cargo build --release --workspace --target aarch64-unknown-linux-musl

# ── ২) কার্নেল + DTB (§৩.৪) ─────────────────────────────────────────────
make -j"$(nproc)" Image.gz dtbs          # আউটপুট: Image.gz + sdm845-oneplus-fajita.dtb

# ── ৩) rootfs (EROFS, dm-verity hash tree সহ) ────────────────────────────
python3 build/mkrootfs.py --target oneplus-fajita \
  --bins target/aarch64-unknown-linux-musl/release \
  --apps apps/*/out/*.nilax --verity --out out/oneplus-fajita/system.img

# ── ৪) initramfs + boot.img ──────────────────────────────────────────────
python3 build/mkinitramfs.py --out out/oneplus-fajita/nilos-initramfs.cpio.gz
python3 tools/mkbootimg.py \
  --kernel Image.gz --ramdisk out/oneplus-fajita/nilos-initramfs.cpio.gz \
  --dtb sdm845-oneplus-fajita.dtb \
  --cmdline "$(cat targets/oneplus-fajita/cmdline.txt)" \
  --header_version 0 --base 0x0 --kernel_offset 0x8000 \
  --ramdisk_offset 0x1000000 --tags_offset 0x100 --pagesize 4096 \
  --output out/oneplus-fajita/boot.img

# ── ৫) vbmeta সাইনিং (§৪.৩) + userdata (f2fs, fscrypt-ready) ─────────────
avbtool make_vbmeta_image ... --output out/oneplus-fajita/vbmeta.img
mkfs.f2fs -f -O extra_attr,inode_checksum,sb_checksum,encrypt \
  out/oneplus-fajita/userdata.img

# ── ৬) ফ্ল্যাশ (ফোন fastboot-এ; registry-তে flashing_allowed=true সচেতনভাবে) ──
fastboot flash vbmeta_a out/oneplus-fajita/vbmeta.img
fastboot flash boot_a   out/oneplus-fajita/boot.img
fastboot flash system_a out/oneplus-fajita/system.img
fastboot flash userdata out/oneplus-fajita/userdata.img
fastboot set_active a
fastboot reboot
```

QEMU প্রথমে (সবসময়): `python3 build/qemu-smoke.py --target qemu-aarch64` — সবুজ না হলে ফোনে ফ্ল্যাশ নিষেধ।
