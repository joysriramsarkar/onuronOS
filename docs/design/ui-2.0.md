# OnuronOS UI 2.0 — “নীল-শাঁখা” ভিজ্যুয়াল সিস্টেম

- **Status:** implemented in the simulator shell; not yet validated on a physical panel.
- **Owning layer:** `nilshell` / NilUI shell chrome (`nilsim/src/ui.rs`, `screens.rs`,
  `apps.rs`). Android compatibility screens are unaffected in architecture.
- **Supersedes visually:** the 1.7 violet system recorded in `docs/ui-design-spec.md`.
- **Canvas:** unchanged — 390×796 logical px (2× the 780×1592 reference art).

## 1. কেন বদলাল

1.7-এর সমস্যা একটাই বাক্যে: **ground, card আর icon-tile একই ভায়োলেট hue-তে
ছিল**, তাই প্রতিটি সারফেসের ওজন সমান হয়ে গিয়েছিল এবং UI একটি টেমপ্লেটের মতো
পড়া যেত। এর সাথে ছিল: সব অ্যাকশনে একই রকম ভরা বেগুনি, সংখ্যাহীন স্পেসিং-হায়ারার্কি,
এবং হোমে আটটি রঙিন letter-tile যা Android-কে নেটিভ অ্যাপের সমান ওজন দিয়ে দিত।

2.0 তিনটি সিদ্ধান্তে দাঁড়ায়:

1. **কালি-কাগজের গ্রাউন্ড।** গভীর ইন্ডিগো কালি, উষ্ণ শাঁখা-আইভরি টেক্সট। কার্ড
   আর গ্রাউন্ডের পার্থক্য ভরাট রঙে নয়, চুলের-লাইন বর্ডারে।
2. **পিতল শুধু অবস্থার জন্য।** অ্যাকসেন্ট কখনো সাজসজ্জা নয় — যেখানে কিছু *চালু*,
   নির্বাচিত, বা প্রাথমিক অ্যাকশন, শুধু সেখানে।
3. **Android একটি সাবসিস্টেম, হোমের অংশ নয়।** আটটি letter tile বাদ দিয়ে একটিমাত্র
   “সামঞ্জস্য” কার্ড, যা Android hub খোলে। এটি §1 ও §3 (Android compatibility
   আলাদা) নীতির সাথে UI-কেও মিলিয়ে দেয়।

## 3. টাইপোগ্রাফি

ফন্ট অপরিবর্তিত: bundled **Noto Sans Bengali** (Regular/Bold), কারণ hardware
path-এও একই ফন্ট বিল্ড হয় এবং বাংলা shaping (rustybuzz) ইতিমধ্যেই যাচাই করা।

| ভূমিকা | আকার / ওজন | ব্যবহার |
|---|---|---|
| Hero clock | 54 bold | Home, Lock |
| Screen title | 28.5 bold | প্রতিটি অ্যাপ/সেটিংস পেজ |
| Row title | 15.5 bold | তালিকার প্রাথমিক লাইন |
| Row sub | 12.5 regular, `dim` | দ্বিতীয় লাইন |
| App label | 13 regular, `med` | হোম গ্রিড |
| Section label | 12.5 bold, `med` + 14×2 পিতল রুল | সেকশন শুরু |
| Body/Value | 17 bold, 12–14 regular | স্ট্যাট, নোটিফিকেশন, বাটন |

বাংলা সংখ্যা সব জায়গায় (`০১২৩৪৫৬৭৮৯`); ইংরেজি সংখ্যা শুধু প্রযুক্তিগত মানে
(`x86_64`, `MB` একক ইত্যাদি)।

## 4. জ্যামিতি ও কম্পোনেন্ট

- কার্ড রেডিয়াস **18** (ছিল 16), আইকন-টাইল **14** (ছিল 12), অ্যাপ-টাইল **19**।
- কার্ড: `card` ফিল + 1px `border`; ছায়া নেই।
- রো: 72 উচ্চতা, 40×40 টাইল, শিরোনাম `x+69`, চেভরন 14, `dim`।
- স্যুইচ: 44×26, থাম্ব 22 আইভরি; চালু = পিতল।
- স্লাইডার: 6px ট্র্যাক + 5px আইভরি থাম্ব (নতুন — আগে থাম্ব ছিল না)।
- প্রাইমারি বাটন: 342×52, রেডিয়াস 16, পিতল ফিল, গাঢ় কালি লেবেল।
- **Ghost button** (নতুন): কার্ড ফিল + হেয়ারলাইন, শুধু লেবেল `danger` — ধ্বংসাত্মক
  কাজ প্রাইমারির সাথে প্রতিযোগিতা করে না। ব্যবহার: “সব মুছুন”।
- চিপ: 32–34 উচ্চতা, পিল; নিষ্ক্রিয় = `tile` + হেয়ারলাইন, সক্রিয় = পিতল।
- কীবোর্ড/পিন: 86×53 কী, রেডিয়াস 16, `tile` ফিল (আগে পিল)।
- জেসচার বার: 160×28 ক্যাপসুল, পিতল হোম-হ্যান্ডেল।
- স্ক্রলবার: 2px, ডান মার্জিনে inset; থাম্ব `dim`।

## 6. আইকন

- স্ট্রোক 1.15–2.0 (আকার-নির্ভর), 24×24 ভিউবক্স, গোলার্ধ জয়েন্ট।
- ঠিক করা হয়েছে: `terminal` (ওভারল্যাপিং প্রম্পট), `apk` (নতুন — nilpkg-এর cube
  থেকে আলাদা), `update` (সার্কুলার অ্যারো, আগে TV আইকন ছিল), ব্যাটারি রো-তে `plus`।
- এমোজি কোথাও নেই।

## 7. যা যাচাই হয়েছে, যা হয়নি

**যাচাই (এই ওয়ার্কস্পেসে চালানো):**

- `cargo build -p nilsim` — সফল, নতুন warning নেই।
- `nilsim --export-ui <dir>` — 36 পর্দা × ৩ থিম = 108 BMP, সব রেন্ডার হয় (ADR-0012-এ AMOLED যোগ হয়)।
- `nilsim --selftest` — **21 passed, 0 failed** (রাউটিং, টগল, স্লাইডার, পিন,
  নোট persistence, recents সীমা, Android শর্টকাট, prefs, AMOLED/অটো resolution)।
- `cargo test -p nilsim` — 3 passed, 0 failed।
- টোকেনের সব টেক্সট-জোড়ার contrast পরিমাপ করা (§2); AMOLED-এর ivory/brass
  জোড়া Dark-এর মতোই (ground 0x000000, surface #0F0F14/#16161D — §2 প্রয়োগযোগ্য)।

**যাচাই হয়নি (দাবি করা যাবে না):**

- কোনো ভৌত প্যানেলে এই UI চলে না; `/dev/dri` ছাড়া ডেস্কটপ কন্টেইনারে শুধু
  সিমুলেটর রেন্ডার (BMP)।
- Wi-Fi/Bluetooth/ক্যামেরা/ব্যাটারি সেন্সর এখনো সিমুলেটেড state; Camera পর্দা
  এখন সেটি স্পষ্ট করে বলে।
- Wayland compositor ও DRM path অপরিবর্তিত; এই কাজ তাদের সক্ষমতা বাড়ায়নি।

**ইচ্ছাকৃতভাবে বাইরে (ADR-0010 অনুযায়ী):** `টার্মিনাল` ও `স্মৃতি` পুরোনো
রেন্ডারারই ব্যবহার করে — মেইনটেইনার আগে এদের অপরিবর্তিত রাখতে বলেছেন। ফলে ডার্ক
থিমেও টার্মিনালের হালকা ব্যাকগ্রাউন্ড থাকছে; এটি একটি পরিচিত অসঙ্গতি, লুকানো হয়নি।

## 8. পরবর্তী ধাপ (প্রস্তাব)

1. ভৌত/QEMU DRM প্যানেলে প্রথম ফ্রেম — তারপরই “hardware-validated” বলা যাবে।
2. Terminal/Memories-কে নতুন টোকেনে আনার সিদ্ধান্ত (মেইনটেইনারের) — ADR-0010
   সংশোধন দরকার।
3. বাংলা ডিসপ্লে ফেস (যেমন Noto Serif Bengali) যোগ করা — এখন শুধু Regular/Bold।
4. `wl_shm` ছাড়া GPU বাফার (linux-dmabuf) না থাকায় প্রতিটি ফ্রেম কপি হয়;
   মসৃণ animation-এর আগে এটি ঠিক করা দরকার।
